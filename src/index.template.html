Su navegador tiene WebGL desactivado

Este mapa usa Kepler.gl / deck.gl, que dibuja con aceleración 3D (WebGL). Para verlo:

  • Firefox: en about:config ponga webgl.disabled en false y active Ajustes → General → Rendimiento → Usar aceleración por hardware.
  • Chrome / Edge / Brave: active Usar aceleración gráfica cuando esté disponible en Configuración → Sistema.
  • Compruebe su soporte en get.webgl.org y actualice los controladores de vídeo.
